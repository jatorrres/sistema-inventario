Descripción del Proyecto

El Sistema de Gestión de Inventario es una aplicación que optimiza la administración y el control de productos de una empresa. Permite registrar nuevos artículos, consultar existencias en tiempo real, actualizar datos de stock y eliminar registros obsoletos de forma ágil y centralizada.

Control Visual de Almacén

Funciones del Sistema

  • Registrar nuevos productos en el catálogo.
  • Consultar existencias y niveles de stock en tiempo real.
  • Actualizar información y precios de productos.
  • Eliminar registros de productos obsoletos o descontinuados.
  • Generar reportes sobre entradas y salidas de mercancía.

Proceso de Uso

  1. Ingresar al sistema
  2. Registrar el producto
  3. Consultar la información
  4. Actualizar existencias
